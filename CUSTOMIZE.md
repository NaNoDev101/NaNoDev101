# Customizing Your README

## Setup
1. On GitHub, create a **public** repository named exactly like your username (`NaNoDev101`). Check the exact spelling and capitalization on your profile.
2. Add `README.md` and the `assets/` folder to its root. This file (`CUSTOMIZE.md`) is optional and can be deleted.
3. GitHub shows that README on your profile page.

## Replace placeholders
- **Username:** if your real username differs from `NaNoDev101`, find-and-replace it in `README.md` (stats URLs and the GitHub badge).
- **LinkedIn / Email:** uncomment the block in the `connect_with_me` section and replace `YOUR_LINKEDIN_URL` and `YOUR_EMAIL`. Then delete the two italic "add your" placeholders.
- **Projects:** in the `featured_projects` table, change the status and replace *Coming soon* with `[View repository](https://github.com/USERNAME/REPO)`. Only mark something "Completed" when it is.

## Adjust the look
- Accent colors: green `#00e5a0`, cyan `#00c8ff`, background `#0b0f14`.
- Banner: edit the text in `assets/banner.svg` with any text editor.
- Skill icons: change the `i=` list at skillicons.dev (e.g. `i=py,cpp,linux`).
- Stats cards: swap `theme=radical` for another theme, or remove a card you don't want.

## Notes
- The stats cards depend on third-party services (github-readme-stats, streak-stats, activity-graph) and can occasionally be slow or down. The README stays readable without them. Contribution cards only show private-repo activity if you enable it in your GitHub profile settings.
- Keep the skills honest. Add technologies only after you've actually used them.
